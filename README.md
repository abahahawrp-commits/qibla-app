# 🕌 Nurul Islam - Islamic Companion App

> Aplikasi pendamping ibadah muslim lengkap, modern, dan ringan berbasis **React 19 + TypeScript + Vite + Tailwind CSS + PWA**.

Dokumentasi lengkap proyek ini telah tersedia di file:
👉 **[DOKUMENTASI_PROYEK.md](./DOKUMENTASI_PROYEK.md)**

---

## ⚡ Fitur Utama
- ⏰ **Jadwal Sholat & Adzan**: Perhitungan astronomis presisi (Kemenag RI, MWL, Umm Al-Qura, dll.) dengan notifikasi audio.
- 📊 **Visualisasi Kepatuhan Sholat**: Grafik interaktif Recharts (mingguan & bulanan) untuk melacak kedisiplinan ibadah.
- 🧭 **Kompas Arah Kiblat**: Menggunakan sensor magnetometer real-time dengan feedback haptic getaran saat tepat menghadap Ka'bah.
- 📖 **Al-Qur'an Digital 30 Juz**: 114 Surah lengkap dengan teks Arab bertasydid, transliterasi Latin, terjemahan Indonesia, dan audio murottal Syekh Mishary Rashid Alafasy.
- 📿 **Tasbih Digital**: Penghitung zikir fleksibel dengan target putaran dan feedback audio/getar.
- 🤲 **Doa Harian & 99 Asmaul Husna**: Kumpulan doa shahih lengkap dengan keutamaan serta 99 Asmaul Husna dan audio pelafalan.
- 🧠 **Kuis Islami Interaktif**: Game kuis aqidah, sirah, fiqih, qur'an dengan timer, lifeline, streak, dan leaderboard skor.
- 🕋 **Panduan Lengkap Ibadah Umroh**: Manasik 6 langkah, counter Thawaf & Sa'i 7 putaran, peta Miqat, larangan ihram, dan checklist perlengkapan.
- 📱 **PWA & Offline Ready**: Service worker caching cerdas yang memungkinkan aplikasi tetap berjalan saat tidak ada koneksi internet.

```bash
# Menjalankan development server

# Memeriksa tipe data (lint)

# Membangun versi produksi
npm run build
```
